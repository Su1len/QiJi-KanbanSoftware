# 骐骥看板 — 全功能清单

本文档按界面区域逐一列出软件中每一个可用的功能点，用于测试用例编写和回归验证。

---

## 一、顶部导航区

### 1.1 搜索框
| # | 功能 | 说明 |
|---|------|------|
| 1 | 关键词搜索 | 输入文本后回车或点击搜索图标，筛选当前日期下匹配的任务 |
| 2 | 搜索范围 | 搜索覆盖：任务名称、事务内容、目标(purpose)、注意要点(hints)、实现路径(approach)、相关方(relevants) |
| 3 | 空搜索 | 搜索框为空时显示当天全部任务 |
| 4 | 搜索图标 | 圆角输入框，左侧搜索图标 |

### 1.2 日期导航栏
| # | 功能 | 说明 |
|---|------|------|
| 5 | 日期显示 | 格式：`YYYY年 第WW周 MM月DD日`（例如：2026年 第1周 01月01日） |
| 6 | `<<` 按钮 | 向前切换一个月 |
| 7 | `<` 按钮 | 向前切换一周 |
| 8 | `>` 按钮 | 向后切换一周 |
| 9 | `>>` 按钮 | 向后切换一个月 |
| 10 | 周计算规则 | 1月1日所在周为第1周（非 ISO 8601） |
| 11 | 日期默认值 | 打开软件时默认显示当天日期 |
| 12 | 日期导航切换时 | 切换日期后，星期选择器自动高亮该日对应的星期 |

### 1.3 星期选择器
| # | 功能 | 说明 |
|---|------|------|
| 13 | 七个星期按钮 | 一、二、三、四、五、六、日 |
| 14 | 默认选中 | 打开软件时默认高亮今天的星期 |
| 15 | 点击切换日期 | 点击某个星期按钮，切换到当前周对应日期 |
| 16 | 跨周切换 | 点击的日期不在当前周时，自动更新日期导航栏的周范围 |
| 17 | 高亮样式 | 选中按钮背景加深，使用主题强调色 |

### 1.4 项目视图下顶部导航的隐藏
| # | 功能 | 说明 |
|---|------|------|
| 18 | 日期控件隐藏 | 切换到项目视图后，日期导航栏和星期选择器自动隐藏 |
| 19 | 搜索框保留 | 项目视图下搜索框仍然显示 |

## 二、核心看板区（日期视图 / KanbanBoard）

### 2.1 表格列定义（详细模式）
| # | 列名 | 宽度 | 功能 |
|---|------|------|------|
| 20 | 编号 | 5% | 大写字母编号（A, B, C...），按优先级降序排列 |
| 21 | 任务列表 | 22% | 主任务名正常显示；子任务缩进 20px + 灰色字体 |
| 22 | 子任务 | 18% | 主任务行：显示子任务 Tag（按状态着色）；子任务行：不显示 |
| 23 | THEMRPR | 22% | 主任务行显示目标(purpose)摘要 + 悬停显示全部8字段；子任务行显示差异字段 + 悬停详情 |
| 24 | 后序 | 8% | 子任务行显示下一个子任务名（只读）；主任务行不显示；无后序显示灰色"无" |
| 25 | 事务内容 | 15% | 显示 content 字段，空则显示"-" |
| 26 | 任务状态 | 10% | 彩色 Tag：进行中(蓝)、暂搁置(橙)、已取消(灰)、已完成(绿) |

### 2.2 表格列定义（简易模式）
| # | 列名 | 宽度 | 说明 |
|---|------|------|------|
| 27 | 编号 | 5% | 同详细模式 |
| 28 | 任务列表 | 75% | 同详细模式 |
| 29 | 任务状态 | 20% | 同详细模式 |

### 2.3 表格交互
| # | 功能 | 说明 |
|---|------|------|
| 30 | 点击主任务行 | 选中该任务，行高亮（accent色10%透明），底部操作栏更新 |
| 31 | 子任务展开 | 每个有子任务的主任务自动展开其子任务行 |
| 32 | THEMRPR 悬停 | 鼠标悬停在 THEMRPR 列的 `ⓘ` 图标上，Tooltip 显示完整8字段 |
| 33 | THEMRPR 编辑入口 | 点击 THEMRPR 单元格弹出 TaskFormDialog |
| 34 | 列宽自适应 | `table-layout: fixed`，百分比宽度，窗口缩放时等比例调整 |
| 35 | 空状态 — 名言 | 任务列表为空时显示随机名言（12条中随机），作者署名 |
| 36 | 空状态 — Tips | 随机显示一条使用技巧（7条中随机） |
| 37 | 空状态 — 行动引导 | 底部引导文字："点击下方'+ 新建主任务'，开始你今天的作战计划" |
| 38 | 空状态 — 无闪烁 | 切换日期时加载中显示"加载中..."，不闪现表头 |
| 39 | 空状态 — 名言兜底 | quotes.json 加载失败时兜底显示孙海鸥老师语录 |
| 40 | 滚动 | 表格区域 `scroll={{ y: 'calc(100vh - 400px)' }}` |

### 2.4 编号算法
| # | 功能 | 说明 |
|---|------|------|
| 41 | 字母递增 | A → B → ... → Z → AA → AB → ... |
| 42 | 排序规则 | 优先级降序 → 创建时间升序 |
| 43 | 删除后重排 | 删除任意位置任务后，剩余任务字母连续重排 |
| 44 | 优先级变更重排 | 修改任务优先级后，当日全部任务字母重排 |
| 45 | 每个日期独立编号 | 不同日期的编号相互独立，各自从 A 开始 |
| 46 | 编号与排序一致 | `reassignLetters` 和 `getMainTasksByDate` 使用相同 ORDER BY |

### 2.5 THEMRPR 继承机制
| # | 功能 | 说明 |
|---|------|------|
| 47 | 子任务继承 | 子任务的 THEMRPR 字段为 null 时，显示为"同主任务"或自动继承主任务值 |
| 48 | 差异展示 | 子任务与主任务部分字段不同时，THEMRPR 列拼接显示有差异的字段 |
| 49 | 悬停详情 | 子任务 THEMRPR 悬停 Tooltip 显示该子任务自身的字段值 |

### 2.6 子任务后序链
| # | 功能 | 说明 |
|---|------|------|
| 50 | 后序列显示 | 子任务行"后序"列显示下一个子任务名（只读，灰色"无"表示无后序） |
| 51 | 后序设置（表单内） | 在 TaskFormDialog 的子任务区，通过 Select 选择后序目标 |
| 52 | 后序唯一性 | 一个子任务只能被一个其他子任务指定为后序；冲突时弹出警告 |
| 53 | 环路检测 | 禁止形成环路（A→B→C→A），设置时前端和服务端双重校验 |
| 54 | 后序链跳过 | 点击"完成"后自动跳转到后序子任务；若后序为已完成/已取消则递归跳过 |
| 55 | 后序结构图 | TaskFormDialog 子任务区下方折叠面板展示依赖关系（Unicode 字符画） |
| 56 | 独立子任务 | 后序结构图中，无前序无后序的子任务单独列出 |

### 2.7 主任务状态自动推导
| # | 功能 | 说明 |
|---|------|------|
| 57 | 推导优先级 | 进行中 > 暂搁置 > 全部已取消 > 全部已完成/已取消 → 进行中 |
| 58 | 无子任务例外 | 无子任务的主任务不自动推导，状态直接存储 |
| 59 | 子任务状态变化触发 | 任何子任务状态变更后，自动重算主任务状态 |
| 60 | 拖拽同步 | 拖拽主任务卡片后，子任务按规则同步 + 主任务状态重新推导 |

### 12.1 main_tasks（主任务表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| letter | TEXT | 字母编号 |
| name | TEXT | 任务名称 |
| content | TEXT | 事务内容 |
| status | TEXT | 进行中/暂搁置/已取消/已完成 |
| purpose | TEXT | 目标 |
| resources | TEXT | 资源 |
| duration | TEXT | 原定工期 |
| effect | TEXT | 预期效果 |
| hints | TEXT | 注意要点 |
| approach | TEXT | 实现路径 |
| relevants | TEXT | 相关方及接洽人 |
| priority | INTEGER | 优先级（0-10） |
| project_name | TEXT | 所属项目名（nullable） |
| project_pinned | INTEGER | 项目置顶标记（0/1） |
| created_at | TEXT | 创建时间 ISO |
| updated_at | TEXT | 更新时间 ISO |
| task_date | TEXT | 任务创建日期 YYYY-MM-DD |

### 12.2 sub_tasks（子任务表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增 |
| main_task_id | INTEGER FK | 关联主任务（CASCADE DELETE） |
| name | TEXT | 子任务名称 |
| status | TEXT | 进行中/暂搁置/已取消/已完成 |
| sort_order | INTEGER | 排序 |
| next_sub_task_id | INTEGER | 后序子任务 ID |
| purpose~relevants | TEXT (nullable) | THEMRPR 7 字段，null=继承主任务 |
| completed_at | TEXT | 完成时间 |
| created_at / updated_at | TEXT | 时间戳 |

### 12.3 daily_records（每日任务记录表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增 |
| main_task_id | INTEGER FK | 关联主任务（CASCADE DELETE） |
| task_date | TEXT | 日期 YYYY-MM-DD |
| created_at | TEXT | 记录创建时间 |
| UNIQUE(main_task_id, task_date) | | 每个任务每天唯一 |

### 12.4 progress_reports（进展报告表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增 |
| sub_task_id | INTEGER | 子任务 ID |
| main_task_id | INTEGER | 主任务 ID |
| report_text | TEXT | 报告文本 |
| time_cost | TEXT | 耗时字符串 |
| created_at | TEXT | 记录时间 |

### 12.5 retrospectives（复盘表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增 |
| main_task_id | INTEGER | 关联主任务（UNIQUE） |
| purpose_actual ~ relevants_actual | TEXT | 8 个复盘维度 |
| lessons | TEXT | 经验教训 |
| created_at | TEXT | 创建时间 |

|------|------|------|
