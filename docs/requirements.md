# 骐骥看板 — 需求规格说明

## 产品概述

骐骥看板是一款运行在 Windows 上的本地桌面看板软件，用于个人任务管理。所有数据存储在本地，无需网络连接（AI 助理功能除外）。

## 技术约束

- **平台**：Windows 桌面
- **窗口比例**：16:9（建议 1280x720 或 1920x1080）
- **部署方式**：完全本地运行
- **数据存储**：本地 SQLite 数据库

---

## 模块一：全局布局

### 1.1 左侧导航栏
- 宽度：窗口总宽度的 1/32
- 背景色：稍深于主视图区
- 左下角固定放置"设置"图标按钮（齿轮图标）
- **交互**：点击齿轮图标，弹出设置模态框（覆盖层）

### 1.2 主视图区
- 位于左侧导航栏右侧，占据剩余所有空间

---

## 模块二：顶部导航区

### 2.1 搜索框
- 位置：主视图区最上方，居中
- 样式：圆角输入框，左侧搜索图标
- **功能**：输入关键词 → 回车或点击图标 → 筛选看板任务列表

### 2.2 日期导航栏
- 位置：搜索框下方，居中
- 布局：`<<` | `<` | 日期文字 | `>` | `>>`
- 日期格式：`YYYY年 第WW周 MM月DD日`
- 按钮功能：
  - `<<`：向前一个月
  - `<`：向前一周
  - `>`：向后一周
  - `>>`：向后一个月
- 周计算规则：1月1日所在周为第1周

### 2.3 星期选择器
- 位置：日期导航栏下方
- 七个按钮：`一` `二` `三` `四` `五` `六` `日`
- 默认选中"今天"对应的星期
- 选中按钮背景加深（主题色高亮）

---

## 模块三：核心看板区

### 3.1 看板表格
- 表格列：编号 | 任务列表 | 子任务 | THEMRPR | 事务具体内容与执行情况评估 | 任务状态
- 行可点击选中，与底部操作栏联动

### 3.2 任务编号规则
- 格式：大写字母递增（A, B, C, ..., Z, AA, AB, ...）
- 排序规则：优先级高 → 编号靠前；优先级相同 → 按建立时间排序

### 3.3 THEMRPR 列显示逻辑

THEMRPR 包含 8 个字段：目标、资源、工期、预期效果、注意要点、实现路径、相关方及接洽人、优先级。

**主任务**：
- 默认显示"目标(purpose)"字段
- 单元格右侧悬停图标(ⓘ)，Tooltip 显示完整 8 字段

**子任务**：
- 与主任务完全相同时：显示"同主任务"，字体颜色较浅
- 部分不同时：仅显示被修改字段的拼接（如 `工期:2天; 接洽人:张总`）
- 同样有悬停图标，Tooltip 显示子任务独立字段

**编辑入口**：点击 THEMRPR 单元格 → 迷你编辑窗 → 修改任意字段

## 模块四：底部状态与操作区

### 4.1 左下：进展报告
- 只读文本区域，自动刷新
- 格式：`[时间戳] 完成 [子任务名] (属于 [主任务名])，主任务共耗时 [耗时计算]`
- 耗时计算：子任务完成时间 - 主任务建立时间
- 触发：子任务状态变为"已完成"时自动追加

### 4.2 右下：当前任务详情与操作

**操作按钮栏**（6个按钮）：
1. `+ 新建主任务`
2. `→ 下一子任务`
3. `✅ 完成并切至下一子任务`
4. `❌ 放弃并切至下一子任务`
5. `🤖 AI助理创建/修改任务`
6. `🗑️ 删除当前主任务`

**当前任务信息**（3行只读）：
- 当前主任务：[名称]
- 当前子任务：[名称]
- 当前任务要点：[hints]

### 4.3 按钮行为

| 按钮 | 行为 |
|------|------|
| 新建主任务 | 弹出任务表单对话框 |
| 下一子任务 | 焦点切到下一个子任务 |
| 完成并切至下一子任务 | 子任务状态→已完成 → 生成报告 → 切下一子任务 |
| 放弃并切至下一子任务 | 子任务状态→已取消 → 切下一子任务 |
| AI助理 | 弹出 AI 对话框 |
| 删除当前主任务 | 确认框 → 物理删除（级联删除子任务和报告） |

## 模块五：设置界面

模态框，含 4 个选项卡：

### 5.1 换肤
- 显示预设主题配色缩略图
- 点击缩略图 → 实时预览 → 点"应用"按钮存储

### 5.2 导出任务
- 日期范围选择器（开始—结束）
- "导出为 Excel"按钮 → 生成 .xlsx 文件
- 内容：选定范围内主任务 + 子任务 + THEMRPR + 进展报告

### 5.3 数据管理
- 红色按钮：`一键删除所有任务`
- 确认流程：输入"确认删除"后方可执行

### 5.4 API 密钥管理
- 首次：输入 API 密钥 + 设置访问密码 → 加密存储
- 后续：输入密码 → 查看/修改已存储密钥
- 加密方式：AES-256-GCM

## 模块六：任务表单对话框

### 6.1 启动方式
- "新建主任务"按钮
- 编辑已有任务时

### 6.2 表单字段

| 字段 | 类型 |
|------|------|
| 任务列表 | 文本输入框 |
| 子任务 | 动态列表，可添加/删除行 |
| 目标(purpose) | 文本输入 |
| 资源(resources) | 文本输入 |
| 工期(duration) | 文本输入 |
| 预期效果(effect) | 文本输入 |
| 注意要点(hints) | 文本输入 |
| 实现路径(approach) | 文本输入 |
| 相关方及接洽人(relevants) | 文本输入 |
| 优先级(priority) | 文本输入 |
| 事务具体内容与执行情况评估 | 多行文本域 |
| 任务状态 | 下拉框（进行中/暂搁置/已取消/已完成） |
| 系统时间戳 | 隐式记录，用户不可见 |

## 模块七：AI 助理

### 7.1 启动
点击"🤖 AI助理创建/修改任务"

### 7.2 流程
1. 用户输入自然语言文本
2. 发送至 DeepSeek API 解析
3. 弹出预览确认窗（所有字段可编辑）
4. 同名冲突检测 → 提示选择"修改已有"或"创建独立任务"
5. 用户确认后写入数据库

### 7.3 AI 解析目标字段
- 优先级 → 编号排序
- 任务内容 → 主任务名称
- 截止日期 → 相关日期字段
- 注意要点(hints)
- 接洽人(relevants)
- 任务状态 → 默认"进行中"
