# 骐骥看板 — API 自动化测试说明

本文档说明 `test-api.js` 中全部 35 个测试用例的测试目标、API 端点、验证点。

---

## 测试架构

- **零依赖**：仅使用 Node.js 内置 `http` + `child_process` 模块
- **数据库隔离**：启动服务端前备份正式 DB → 测试用独立数据库 → 结束后自动还原
- **AI 端点测试**：依赖环境变量 `QIJI_DEEPSEEK_API_KEY`，若未设置则自动跳过
- **执行方式**：`node test-api.js`

---
