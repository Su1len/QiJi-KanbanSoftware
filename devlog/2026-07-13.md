# 开发日志 — 2026-07-13

## 版本：V0.7.5

## 已完成功能总览

### 一、核心任务管理

- **主任务 CRUD**：新建、编辑、删除主任务。每个主任务含名称、内容评估、任务状态、优先级、12 个 THEMRPR 字段
- **子任务系统**：主任务下挂子任务，子任务可独立设置 THEMRPR 字段（留空则继承主任务）
- **THEMRPR 继承模型**：子任务未设置的字段自动从主任务继承，主任务变更后子任务自动跟随
- **字母编号**：每个日期独立编号 A/B/C...Z/AA/AB，按优先级降序排列。插入/删除时自动重排

### 二、日期与周视图

- **日期导航**：`<<`（前月）、`<`（前周）、`>`（后周）、`>>`（后月）
- **周算法**：1 月 1 日所在周为第 1 周
- **星期选择器**：七个按钮（一~日），点击切换到对应日期
- **搜索**：对任务名、内容、THEMRPR 字段全文检索

### 三、子任务后序系统

- **后序链**：每种子任务可指定"完成后跳转到哪个"，形成工作流水线
- **唯一性约束**：一个子任务只能被一个其他子任务指定为后序
- **环路检测**：A→B 后 B 不能再→A，防止死循环
- **表单内可视化**：新建/编辑任务时可展开子任务的 THEMRPR 详情 + 状态，子任务区显示后序依赖结构图（Unicode 字符画）
- **导航逻辑**：完成/放弃子任务 → 自动跳到后序指定的下一个，已完成/已取消自动跳过

### 四、简易模式与详细模式

- **首次启动引导**：WelcomePage 两张卡片选择简易/详细
- **简易模式**：看板只显示编号、任务列表、任务状态三列；表单只显示名称、状态、优先级、内容
- **详细模式**：全部 7 列 + THEMRPR 9 字段 + 子任务区
- **即时切换**：设置中 Switch 一键切换，数据不丢失

### 五、项目视图

- **项目聚合**：任务填写 `project_name` 后自动归入对应项目
- **AutoComplete**：表单中填写项目名时自动提示已有项目列表
- **项目面板**：折叠面板按项目分组，显示进度（已完成/总数）
- **置顶**：重要项目可置顶，置顶项目优先排列
- **双击编辑**：项目视图中双击任务即可弹出编辑表单
- **视图切换**：侧边栏日历/文件夹图标切换日期视图与项目视图

### 六、主题换肤系统

- **4 套内置主题**：深蓝（默认）、墨绿、暖橙、浅灰
- **14 色 CSS 变量动态注入**：切换即时生效，无需重启
- **免编译新主题**：放入 `themes/` 文件夹 → 重启自动扫描 → 下拉菜单显示
- **hidden 标记**：模板主题可隐藏
- **背景叠加**：支持图片/渐变叠加到 KanbanBoard、MainContent、BottomBar 三个区域
- **文案覆盖**：主题可替换按钮和标签上的文字
- **字体覆盖**：标题和正文字体可定制

### 七、AI 助理（DeepSeek）

- **自然语言解析**：输入口语化描述 → 生成 THEMRPR 结构化任务
- **多任务拆分**：一句话包含多个任务时自动拆分
- **预览卡片**：解析结果以卡片形式展示关键字段
- **逐个创建**：确认后依次弹出 TaskFormDialog，AI 数据预填，最多 10 个
- **API 密钥加密存储**：AES-256-GCM 加密，支持密码保护

### 八、复盘系统

- **复盘表**：`retrospectives` 表，记录计划 vs 实际的 8 个 THEMRPR 维度对比
- **左右分栏**：左侧展示原始任务数据，右侧填写复盘
- **自动工期计算**：根据子任务完成时间累加预填实际工期
- **Markdown 导出**：服务端生成表格格式 report，浏览器下载 `.md` 文件
- **入口**：已完成任务的底部操作栏显示"复盘"按钮

### 九、进展报告与每日战报

- **自动报告**：子任务完成时自动生成 `[时间戳] 完成 [子任务] (属于 [主任务])，主任务共耗时 [X天X小时]`
- **每日战报**：设置定时 → 到时自动生成"📊 XXXX-XX-XX 战报"
- **工期顺延**：启动时将过期未完成任务移至当天，duration 减 1

### 十、备份与恢复

- **导出备份**：服务端流式下载 `kanban.db`，浏览器弹出"另存为"对话框
- **导入恢复**：上传 `.db` 文件 → 校验 SQLite 文件头 → 确认覆盖 → 重启生效

### 十一、设置与工具

- **5 个设置页签**：换肤 / 导出任务 / 数据管理 / API 密钥 / 关于
- **Excel 导出**：按日期范围导出为 .xlsx
- **一键删除**：需输入"确认删除"文字防误触
- **关于界面**：版本号、开发者署名"桑尼之子 昭深"、孙海鸥老师语录、更新日志

### 十二、系统稳定性

- **端口自动回退**：3456 → 3457 → ... → 3462
- **父进程监听**：NW.js 关闭后 Express 自动退出
- **ErrorBoundary**：React 渲染崩溃时显示友好提示 + 刷新按钮
- **API 超时**：15 秒超时 + 中文错误消息
- **事务保护**：`createMainTask`、`updateMainTask`、`autoCarryForward` 用 `db.transaction()` 包裹
- **孤儿数据清理**：删除主任务时同步清理 `progress_reports`

### 十三、空状态体验

- **名人名言**：12 条随机名言（quotes.json），加载失败时兜底显示孙海鸥老师语录
- **使用技巧**：随机展示产品 Tips
- **行动引导**：底部引导文案
- **无闪烁切换**：切换日期时空状态平滑过渡，不闪现表头

### 十四、自动化测试

- `test-api.js`：零依赖回归测试，35 个用例，覆盖创建/更新/删除/搜索/后序/状态回退/加密链路/AI 解析等
- 数据库隔离：测试用独立数据库，结束后自动还原
